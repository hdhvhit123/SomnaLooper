Optional recorded sounds.

Every built-in sound is synthesized on the device, so this folder can stay empty.
To replace a synthesized sound with a real recording, drop an OGG Vorbis/Opus file here
named after the sound id, e.g. "rain_roof.ogg", "cafe.ogg", "cat_purr.ogg".
It is detected automatically and looped seamlessly with the crossfade looper.
